# Undercover

Jeu d’ambiance pour 3 à 20 joueurs, sur un seul téléphone. Ajoute-le à l’écran d’accueil pour jouer en plein écran.

Les **civils** partagent le même mot. Les **undercovers** ont un mot voisin. **Mr. White** n’a rien. On donne un indice, on discute, on élimine.

Une liste de paires est fournie. Tes paires perso restent dans le navigateur.

```bash
npm install
npm run dev
```

Sur iPhone : Safari → **Partager** → **Sur l’écran d’accueil**.  
Sur Android : Chrome → menu → **Ajouter à l’écran d’accueil**.
